# Product identity

Mechanism signature: a frozen protocol and original result, a role-bound rerun, a post-assessment challenge window, and consensus resolution of conflicting reruns.

Product metaphor: a laboratory notebook whose pages are handed from author to rerunner to auditor.

Voice: measured field notes. Each section starts with an observation, then records the source and exact number.

Interface grammar: vertically stacked paper sheets, a handwritten progress margin, a number-line result plot, and one action on each page. No control-room rail, no dashboard cards, and no URL grid.

Evidence story: sources become numbered notebook exhibits. Values and digests survive even when the final classification changes after an audit.
